# NDDev Builder for Qwen Code

Use Qwen Code's native extension system. A Qwen extension is a directory with a
`qwen-extension.json` manifest and optional `QWEN.md`, `skills/`, `agents/`,
`commands/`, MCP servers, channels, and extension settings.

Do not invent a Qwen marketplace manifest for this package. Project Qwen Code
capabilities directly onto the native extension, skill, and subagent surfaces.
